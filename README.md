1. **Install Ollama:** Download and install [Ollama](https://ollama.com/).
2. **Download Repository:** Download and extract this folder.
3. **Open in VS Code:** Open the folder in VS Code.
4. download Ollama

## 🛠 Features
- **Intelligent Reformulation:** Turns raw input into expert questions.
- **Auto-Notifications:** Sends leads to your principal via email.
- **Session Tracking:** Limits to 5 questions per session.
